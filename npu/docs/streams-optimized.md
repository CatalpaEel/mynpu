# Matrix、CNN、Vector Stream精简

功能改动提交 `9b55588`，基线为 `c0d288a`。保持原来的任务ABI、精度、转置、自定义跨度、流FIFO、量化开关、缓存容量和8项队列。没有减少计算单元或把功能移到CPU。

## Matrix

原先每个K步骤为8个元素重新计算乘法地址，写回还计算行号乘N。现在在任务入口准备字节步长：

| 向量 | 跨行/列步长 | K步长 |
|---|---|---|
| 非转置A | LDA×元素字节数 | 元素字节数 |
| 转置A | 元素字节数 | LDA×元素字节数 |
| 非转置B | 元素字节数 | LDB×元素字节数 |
| 转置B | LDB×元素字节数 | 元素字节数 |

块入口形成4个A与4个B指针；每个被接受的MAC步骤递增指针，切换输出块时更新块起点。输出使用8位线性索引递增、跨行跳步，不再反复乘行号与N。没有增加初始化状态或读取批次。

输入和原始D使用15位孔径内偏移，因为父级MMIO已经检查完整张量跨度，合法地址均在既有SRAM/RF/流孔径内。普通地址保持线性推进，FIFO独立保持低8位环绕。**量化目的地址仍保留完整32位进位与访存错误行为**，没有通过截断地址掩盖越界。

8×32bit操作数暂存、13位字标签、相同字合并和3个gather槽全部保留。新增边界测试覆盖4096元素行跨度及SRAM/RF末端，原有所有32组标志、尾块、多块和量化测试继续通过。

## CNN

每个卷积输入行只形成一次像素选择：当前32位字加下一字低16位，组成48位组合窗口，再根据字节偏移选出连续三个像素。三行分别产生3个像素，共享字选择和读返回转发逻辑。

左padding且真实像素恰在字边界时，row_cursor可能位于前一个字的被屏蔽字节；该情况单独对齐到首个真实像素，避免误读下一字。像素mask与有效MAC计数保持一致。

位置计数器限定为3位（0..7），输入通道计数器限定为4位（0..15）；任务上限仍为8位置、16输入通道。36B循环预取窗口、双份9B权重、双seed、同拍返回转发以及独立RF写口均保留。

新增193个CNN任务测试覆盖stride1/2、左右上下边界、非字对齐行、1/2/3/4/8/16输入通道、SRAM/RF组合，以及跨多个字的FIFO输入。卷积结果用独立整数循环计算，包含输入零点扣除。

## Vector

- 将部分字节打包数据和待写回结果合并为一个32位缓冲，按任务入口和写确认清空，保留原byte enable与尾部行为。
- 直接模式的B地址使用此时闲置的r1保存，程序模式继续完整保留4个32位临时寄存器；模式切换在新任务入口初始化。
- LD32的地址相加使用既有ALU的INT32 ADD，删除Stream中的独立地址加法。SIMD8任务执行LD32时仍强制32位地址计算，立即数为完整有符号20位，不消耗或更新CF。
- 直接模式取数直接连接批读返回数据，去掉只在无效周期使用的操作数选择；尾部写掩码改为小型真值表。

程序ABI、4×INT8/1×INT32运算、LD32、进位及字对量化指令均保持支持。没有减少Vector功能或寄存器数量。

## 验证

[机器报告](../reports/streams_optimized_validation.json)逐项核对源码/固件哈希。共21组验证，其中15组涉及改动的测试重新运行，6组完全未改动模块按源码哈希复用既有结果。

| 同一固件 | 优化前周期/张 | 优化后周期/张 |
|---|---:|---:|
| 默认VPG2后处理 | 29,173 | 29,173 |
| 共享QT01后处理 | 27,432 | 27,432 |
| 旧标量二进制兼容路径 | 30,710 | 30,710 |

每条路径均测试10张MNIST；两条新软件路径另外各验证60个中间层张量、17,940字节逐字节匹配golden。Matrix、CNN、Vector的运算、故障恢复、队列、JTAG和单元互联均通过。固件、权重、输入和golden没有改动。

[同配置面积与时序结果](streams-optimized-area.md)单独列出三种Stream和整芯片的变化。面积测量包含两块SRAM，不含PAD与PNR开销。

复现功能测试示例：

```bash
python3.12 npu/scripts/run_vcs.py --suite cnnstream --macro --tag STREAM_CNN
python3.12 npu/scripts/run_vcs.py --suite outergemm --macro --tag STREAM_MATRIX
python3.12 npu/scripts/run_vcs.py --suite vectorprogram --tag STREAM_VECTOR
python3.12 npu/scripts/run_vcs.py --suite vectorsimd --macro --tag STREAM_SIMD
```
