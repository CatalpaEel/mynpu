# 纯触发器、保持完整计算能力的面积评估

本轮约束：不新增数据锁存器；不减少 Matrix/CNN/Vector 的计算精度、并行度或启动吞吐；CPU 计算硬件、RF/FIFO 容量和带宽、任务队列深度保持原版。正式 RTL 暂未改动，最新完整后端仍指向原来的 all4 归档。

旧目录 `../20261109-control-area24` 中采用 RF/FIFO 数据锁存器的方案已被用户否决。其中 2.48267 / 2.47145mm² **不作为本轮可采用结果**。本目录的两个 RF/FIFO 源文件均来自原版冻结快照。

## 本轮修改

1. **MMIO 配置存储精简**：M/N 保留5位、K保留9位、Vector长度保留13位，模式/精度/间距按实际编码位宽存储。所有原先支持的合法配置仍可表示；任务 FIFO 的125位 Matrix /166位 Vector描述符及各4深度不变。
2. **完整范围检查交软件**：MMIO 不再重复计算矩阵完整跨度及源/目的重叠，Vector连续布局使用初始访问/编码检查。`npu/sw/task_graph.py` 的高层规划器已有跨度、布局和重叠验证。Raw MMIO 仍由调用软件保证合法性和安全性，尤其 Matrix 15位游标的回绕不能依靠 Xbar 检出。
3. **量化配置精简**：显式将 control 的高30位、shift的高26位写零。原来硬件只接受 control 0..3、shift 0..32，因而合法写入语义不变；32×32→64乘法、舍入、偏置、零点、上下限及II=1流水线保留。
4. **去掉重复地址快照**：Matrix/Vector Stream在读批次活动期间已经保持地址稳定，`npu_multi_read` 增加 `STABLE_INPUTS` 参数复用这些寄存器。默认参数仍保留原来的地址快照语义；仅两个已验证的 Stream 启用复用。仿真断言检查直到批次退休前地址没有变化。不新增流水级，不更改响应周期或 RF 端口数。

配置内部缩窄会改变非法高位写入的读回/拒绝行为：例如写入超出精度字段的值会截断，高层软件必须在生成合法字节码/提交任务前检查。它不保证兼容旧测试中“非法高位必须由硬件拒绝”的约定。本目录是可审查的候选，未据此宣称所有旧负向 ABI 测试兼容。

## 硬件能力保持

| 部分 | 保持的配置 |
|---|---|
| Matrix | 原版16路有符号INT16 MAC，逻辑4×4外积，任意INT16数值的单拍启动 |
| CNN | 原版9路MAC、窗口预取与权重缓冲 |
| Vector | 原版INT32 / 4路INT8 SIMD指令和乘法 |
| 共享量化 | 完整32×32→64、原有精度和II=1 |
| RF | 原版触发器、256B、8物理bank、原有ordinary/gather接口 |
| 流 FIFO | 原版触发器、4通道×8 words，原有字节掩码、旁路和反压 |
| 命令队列 | Matrix/Vector/CNN各4 |
| CPU/JTAG | 原版CPU计算硬件、调试模块及SBA接口 |

`collect.py` 核对原版计算核及 RF/FIFO 源码 SHA。三个完整综合脚本没有引用被否决的数据锁存器源文件。

## 交叉综合

额外候选 `full_ff20_dc_matrix` 使用 Design Compiler 对**原版** `npu_matmul.sv` 生成的映射网表，并在 Genus 中保留该实现、重新连接真实 SRAM Liberty/LEF。原版计算RTL未修改，不采用8路MAC或INT16分时；它只是同一运算的另一种门级实现。

该 Matrix 网表已通过2,016条随机命令对照，并接回纯触发器候选运行通用负载、MNIST、单元互连和共享量化测试，周期与原版相同。单模块 DC Cell Area约0.22979mm²，不直接作为整芯面积结论。

DC独立整核尝试缺少可用 SRAM `.db`，因此其整核时序/面积不在此报告中充当完整芯片结果。本轮完整芯片结果以连接原SRAM模型后的Genus报告为准。

## 完整综合

面积均为 Cell Area，**包含两块SRAM合计0.802887182mm²**，不包含PAD与布线后修复开销。原版为2.569744391mm²。三个完整运行均已结束，TNS为0，无未解析模块、悬空驱动或未约束时序路径。

| 候选 | 综合面积 mm² | 综合目标 | 20ns setup WNS |
|---|---:|---:|---:|
| 原版基线 | 2.569744391 | 18ns | +2.0044ns |
| 触发器＋控制精简 | 2.505653332 | 18ns | +2.0048ns |
| 触发器＋面积优先映射 | 2.502439559 | 20ns | +0.0331ns |
| 触发器＋DC Matrix映射 | **2.484228180** | 20ns | **+0.0954ns** |

最佳综合候选减少0.085516211mm²（3.3278%），距2.4仍差0.084228180mm²；**本轮没有达到2.4**。两块SRAM不变，最佳候选标准单元为1.681340998mm²。

20ns候选余量较薄，建议将18ns、2.50565mm²的候选优先用于后续布局布线评估；不能把20ns综合的TNS=0等同于布线后50MHz达标。映射网表扫描确认没有新增数据锁存器：只剩与原版相同的一位CPU时钟门控使能锁存，RF、FIFO数据存储全部保留触发器。

完整数据在 `study.json`、`reports/area.rpt`、`reports/qor.rpt`、`reports/unconstrained_timing.rpt` 和 `reports/latch_inventory.tsv`。

未重新执行本轮候选的布局布线、hold修复或Calibre；不能将综合面积等同于最终可用芯片面积，也不能用旧数据锁存器结果替代纯触发器结果。
